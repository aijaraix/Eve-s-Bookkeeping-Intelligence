# Eve's Bookkeeping — Production Brand Asset Pack

## Canonical identity
**Brand:** Eve's Bookkeeping  
**Descriptor:** Bookkeeping Intelligence  
**Primary tagline:** Clear numbers. Brighter tomorrows.  
**Secondary tagline:** More than bookkeeping. A clearer future.

## Typography
- Display/headlines: **Playfair Display**
- UI/body/navigation: **Inter**
- Recommended Inter weights: 400, 500, 600, 700
- Recommended Playfair Display weights: 400, 500, 600, 700; italic may be used selectively.

Fonts are named here but **font files are intentionally not redistributed**. Obtain them through the project's normal licensed/web-font source.

The owner's original ZIP also contains PNG icon/logo variants and the raster brand-board reference. Those larger binary assets remain part of the owner-supplied handoff package.

## Important production note
The supplied logo vectors are a **clean vector reconstruction of the approved raster brand board**, not an extraction of an original source vector. They are suitable as an implementation master after visual approval, but the geometry should be reviewed at large size before trademark registration or print production.

## Web usage
Use SVG for logos whenever possible. Do not rasterize the logo into hero/background imagery. Keep website headings, pricing, buttons and navigation as HTML/CSS.

## Clear space
Maintain at least 0.25× the emblem diameter around the emblem, and at least the cap-height of the wordmark around horizontal lockups.

## Minimum sizes
- Full horizontal lockup: 180 CSS px wide minimum
- Circular emblem: 24 CSS px minimum
- App mark/favicon: use the supplied small-size assets

## Do not
- Stretch or skew the logo
- Change canonical colors
- Add gradients/effects to the mark
- Place the navy logo on insufficient-contrast dark backgrounds
- Add descriptor text inside tiny app icons

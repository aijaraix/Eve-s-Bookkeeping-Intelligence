# Implementation Plan: AI CPA Core

- **Milestone 1**: Foundation, workspace creation, authentication mock, and monorepo structure.
- **Milestone 2**: Multi-file intake, ZIP batch upload, speech-to-text instruction recording, document explorer shell.
- **Milestone 3**: Hermes 4-agent consensus extraction, OCR fallback, multi-language detection, and fact persistence with source citations.
- **Milestone 4**: Currency normalization, exchange rate historical tables, and deterministic financial validation.
- **Milestone 5**: 10+ financial dashboards (Overview, Income Statement, Balance Sheet, Cash Summary, Review Center, Data Quality, Drill-down evidence).
- **Milestone 6**: Ask AI CPA chat interface with structured tools and mandatory source citations.
- **Milestone 7**: Management reports, quarterly packages, and exports (PDF, XLSX, CSV, JSON).
- **Milestone 8**: Quality reviews, automated testing readiness, and demonstration dataset seeding.

# Raw-Input Capability Matrix

Evidence-derived statuses only: UNTESTED, RUNNING, PASS, CLARIFICATION_PASS, FAIL, BLOCKED, NOT_APPLICABLE.

Dimensions must cross, not live as isolated checklists.

## Document families
Receipts; supplier/customer invoices; credit notes; bank/credit-card statements; purchase orders; packing slips/bills of lading; payroll; POS/merchant/e-commerce settlements; expense reports; loans/amortization; leases; fixed assets; inventory; sales tax/VAT/GST; brokerage/investments; equity/cap-table; CSV/XLS/XLSX; PDF; images/scans; email-derived evidence; mixed engagement boxes.

## Quality/adversity
Native digital, clean/poor scan, phone photo, rotation, crop, fade, compression, long documents, missing pages, duplicates/near-duplicates, contradictions, handwriting/partial handwriting, fragmented/continuation tables.

## Locale
English, Spanish, French, German, Hebrew, Chinese, Japanese, then expand. Exercise locale dates, separators, currencies, tax conventions and document structures.

## Accounting
Cash, AR, AP, revenue, expenses, payroll, inventory, fixed assets/depreciation, debt, leases, equity, tax, investments, FX, intercompany, consolidation, ownership interests, acquisitions/disposals.

## Complexity
Single document → multi-document transaction → account → month/period → company → multi-account → multi-entity → intercompany → multicurrency/multilingual → partial ownership → multinational group.

Every PASS must link to physical examination evidence. Architecture does not imply coverage.

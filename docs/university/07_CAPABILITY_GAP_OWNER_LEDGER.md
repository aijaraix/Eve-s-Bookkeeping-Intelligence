# Capability Gap / Owner Request Ledger

When workers identify a missing capability, create a structured request instead of silently failing or self-expanding privileges.

Required fields:
request ID; requesting agent; examination IDs; observed problem/evidence; frequency; materiality; tools attempted; proposed capability; measurable expected improvement; security/privacy implications; cost/resource implications; suggested implementation if known; priority; status; owner decision; implementation/result evidence.

Examples: OCR/handwriting, language support, spreadsheet/document parser, bank format, specialized accounting knowledge, external data source, model/provider, compute/storage/browser or reconciliation tooling.

Surface requests in Owner Command Center → University → Owner Requests.

Agents may propose. They may not purchase services, expand privileges, expose secrets or change production authorization without owner approval.

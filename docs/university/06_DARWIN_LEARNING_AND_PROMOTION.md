# Darwin Learning and Promotion

Material failure lifecycle:
FAILURE → ROOT CAUSE → CAPABILITY GAP → REMEDIATION PROPOSAL → BOUNDED EXPERIMENT → FAILED-CASE REPLAY → RELATED REGRESSION → SEALED MINERVA HOLDOUT → INDEPENDENT PROMOTION DECISION → CAPABILITY VERSION → MONITORING.

Every repaired material failure becomes permanent regression curriculum.

Do not overfit to known exams; retain hidden holdouts.

Preserve role separation: solver, examiner, proposer and promotion authority. No single agent may propose, grade, approve and promote its own change alone.

Academy success never silently promotes production autonomy or professional approval. Promotions remain governed and auditable.
